FAQ

Windows says "Windows protected your PC" when I run the installer.

That's Microsoft SmartScreen. It shows for new apps from small developers that don't yet have a paid code-signing certificate. Click More info → Run anyway. FrameReady installs per-user, needs no admin rights, and you can see its virus scan results first.

Will it break anything?

Every change is a normal Windows setting (power plan, Game Mode, the same startup switch Task Manager uses). Game Boost records what it changed and "Restore normal" or uninstalling puts it back.

Which graphics cards work?

NVIDIA, AMD and Intel. GPU temperature is shown on NVIDIA cards.

How much does the AI need?

The built-in assistant needs nothing extra. The optional local AI model is a one-time ~2.5 GB download and uses about 5 GB of RAM while it answers (PCs with less than 12 GB RAM get a smaller 1.8 GB model). Already have Ollama? FrameReady uses it.
